# Getting Started and Installation

PowerControllerViewer is designed to run on a Linux system (including a Raspberry Pi) or an Apple Mac. Since this is a Python application it should also run on Windows, but the installation steps will need to be adjusted.

Installation comes in several phases:

1. Install the prerequisites (Python, git, UV)
2. Install the PowerControllerViewer application
3. Configure the application
