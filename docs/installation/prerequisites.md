# Installing the Prerequisites

The prerequisites for the PowerControllerViewer application are:

1. [Python v3.13](https://www.python.org/downloads/release/python-3130/)
2. [UV package manager](https://docs.astral.sh/uv/getting-started/)
3. git

Check which versions are installed:

```bash
python3 --version
uv --version
git --version
```

If Python is missing or older than 3.13, install it using your platform's package manager (for example `sudo apt install python3.13 python3.13-venv` on Linux, or `brew install python@3.13` on macOS). Install UV by following the [UV installation guide](https://docs.astral.sh/uv/getting-started/installation/).
